# Hardware Components

## 1. Introduction
This document describes the main hardware components required to implement the proposed secure enterprise network infrastructure for healthcare systems.

## 2. Network Devices

### 2.1 Router
- Connects the hospital network to external networks.
- Provides routing between different networks.

### 2.2 Layer 3 Switch
- Provides inter-VLAN routing.
- Connects distribution and access network segments.

### 2.3 Layer 2 Switch
- Connects computers, printers, and other endpoint devices.
- Supports VLAN configuration.

### 2.4 Firewall
- Protects the network from unauthorized access.
- Controls incoming and outgoing network traffic.

### 2.5 Wireless Access Point
- Provides wireless connectivity for authorized users.
- Supports secure wireless access.

## 3. Server Infrastructure

### 3.1 DHCP Server
Automatically assigns IP addresses to network devices.

### 3.2 DNS Server
Resolves domain names into IP addresses.

### 3.3 Application Server
Hosts healthcare applications and internal services.

### 3.4 Database Server
Stores and manages healthcare system data with appropriate access controls.

## 4. End Devices
- Desktop computers.
- Laptops.
- Network printers.
- Medical workstations.
- Authorized wireless devices.

## 5. Network Cabling
- Cat6 Ethernet cables.
- Fiber optic cables for backbone connectivity.
- Patch panels.
- Network racks.

## 6. Power and Reliability
- Uninterruptible Power Supply (UPS).
- Backup power infrastructure.
- Proper equipment cooling and ventilation.

## 7. Proposed Simulation Components
The following devices can be represented in Cisco Packet Tracer:
- Routers.
- Layer 2 and Layer 3 switches.
- Servers.
- PCs and laptops.
- Wireless access points.
- Network connections.

## 8. Conclusion
These hardware components provide the physical foundation for a reliable, scalable, and secure healthcare network infrastructure.

Note: The final hardware selection depends on the project budget, network size, and implementation requirements.
